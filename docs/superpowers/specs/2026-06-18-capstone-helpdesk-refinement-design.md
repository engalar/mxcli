# Capstone HelpDesk Refinement Design

**Date:** 2026-06-18
**Status:** Draft
**Project:** academy/zh/capstone-helpdesk/参考实现

## Overview

The existing HelpDesk capstone reference implementation has page/operation gaps and a barebones visual appearance. This spec defines four incremental MDL files that complete the business logic, modernize the UI, add a role-based Dashboard, and apply a branded theme — all without Java/JS Action dependencies.

## Files

| # | File | Focus | Concept |
|---|------|-------|---------|
| 1 | `13-improve-operations.mdl` | Wire missing Assign button, add Priority dropdown, add ticket Delete, add full-text search page | Business completeness |
| 2 | `14-beautify-pages.mdl` | DataGrid card-ify, status badges, priority colors, comment polish | UI modernization |
| 3 | `15-dashboard.mdl` | New Dashboard home page with statistics + overdue alerts | Data visibility |
| 4 | `16-brand-theme.mdl` | Font import, brand color overrides, status/priority color tokens | Brand identity |

## Section Details

### 1. Operations (`13-improve-operations.mdl`)

#### 1a. Assign Agent workflow

- New popup page `HD.SelectAgent_Form` (DataGrid of `HD.Agent` + select button)
- New microflow `HD.ACT_OpenAssignForm(Ticket)`: creates temp object, opens select page
- New microflow `HD.ACT_DoAssign(Ticket, Agent)`: calls existing `HD.ACT_Ticket_Assign`
- `alter page HD.Ticket_Detail` → insert `btnAssign` after `btnSubmit`

#### 1b. Priority dropdown on New/Edit

- `alter page HD.Ticket_NewEdit` → insert `dropdown` with `attribute: Priority` after Description

#### 1c. Ticket Delete

- New microflow `HD.ACT_Ticket_Delete(Ticket)`: confirmation → delete + commit
- `grant execute on microflow HD.ACT_Ticket_Delete to HD.ManagerRole`
- `alter page HD.Ticket_Detail` → insert `btnDelete` (only visible to Manager role)

#### 1d. Full-text Search page

- Enable existing `HD.TicketSearch` entity and `HD.NF_TicketSearch_Apply` nanoflow
- New page `HD.TicketSearch_Overview` with search input + results DataGrid
- Grant view access to all roles

### 2. Beautify Pages (`14-beautify-pages.mdl`)

| Page | Changes |
|------|---------|
| `HD.Ticket_Overview` | Status column → `TicketStatusBadge` widget; Priority column → color-coded text; Overdue → green/red badge |
| `HD.MyTickets_Overview` | Same as Ticket_Overview |
| `HD.Ticket_Detail` | Status row → badge; Priority row → color label; Comment section → dividers + timestamps |
| `KB.Article_Overview` | DataGrid → Gallery card layout with title + summary + status + date |
| `KB.Article_Detail` | Right-side action buttons → inline horizontal group |
| `HD.Ticket_NewEdit` | Form field groups visually separated by LayoutGrid row dividers |

### 3. Dashboard (`15-dashboard.mdl`)

**New non-persistent entity:** `HD.DashboardStats`
- `OpenCount: Integer`
- `OverdueCount: Integer`
- `NewTodayCount: Integer`
- `AvgResponseHours: Decimal (4,1)`

**New microflow:** `HD.DS_DashboardStats` → returns `HD.DashboardStats`
- Queries Ticket counts filtered by status/overdue/today
- Calculates average hours from created → resolved

**New page:** `HD.Dashboard_Home`
```
┌────────────────────────────────────────────────────┐
│ HelpDesk Dashboard                                 │
├──────┬──────┬──────┬───────┤
│ Open │ Over │ Today│ Avg h │
│  12  │  3   │  5   │  4.2  │
├──────┴──────┴──────┴───────┤
│ ⚠ Overdue alerts (top 5)   │
│ ┌─────────────────────────┐│
│ │ "Login err" CRITICAL +2h││
│ └─────────────────────────┘│
├────────────────────────────┤
│ [New Ticket] [All Tickets] │
└────────────────────────────┘
```

**Data container structure:**
- `DataView` (datasource: `HD.DS_DashboardStats` → `HD.DashboardStats`) → 4 stat cards
- `DataGrid` (datasource: `database from HD.Ticket where [IsOverSLA = true]`) → overdue list
- Button group → navigation to existing pages

**Navigation update:**
- Customer → `HD.MyTickets_Overview`
- Agent/Manager → `HD.Dashboard_Home`

### 4. Brand Theme (`16-brand-theme.mdl`)

Appended to `theme/web/main.scss` — pure SCSS variables consumed by Atlas_Core:

```scss
// Font
@import url('https://fonts.googleapis.com/css2?family=Lexend:wght@400;500;600;700&family=Source+Sans+3:wght@400;600&display=swap');

// Brand palette
$brand-primary: #0891B2; $brand-secondary: #22D3EE;
$brand-success: #22C55E; $brand-background: #ECFEFF;
$brand-text: #164E63;

// Status colors
$status-draft: #94A3B8; $status-open: #3B82F6;
$status-inprogress: #F59E0B; $status-resolved: #22C55E;
$status-closed: #6B7280;

// Priority colors
$priority-low: #94A3B8; $priority-normal: #3B82F6;
$priority-high: #F97316; $priority-critical: #EF4444;
```
