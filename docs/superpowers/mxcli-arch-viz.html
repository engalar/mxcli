架构哲学

mxcli 的核心思路：单一强类型 SDK，用自动生成的 gen/* 类型替代手写 BSON 解析器，读写路径统一到 modelsdk/mpr。

⬡ gen/* 类型：codegen 从 Mendix reflection data 自动生成，53 个域，1500+ 类型。字段变更时 regenerate 即可，零手工维护。
⬡ modelsdk/mpr.Reader：唯一的读路径入口，封装所有 BSON 解码细节。消费者只 import 一个包。
⬡ mprread 自由函数：gen-typed 列表器，按域独立，绕开 codec→mpr 循环 import。不对外暴露，是 Reader 的实现细节。
⬡ sdk/mpr（退役中）：手写 BSON parser，~2500 行，目标是完全删除。写路径已迁走 77%，读路径是 Phase 4。

Track B — reader_model.go（需要 Steps 深度字段）
func (r *Reader) ListDataTransformers() ([]*model.DataTransformer, error) {
    // Step 1: 拿 ContainerID
    refs, _ := r.ListUnitsByType("DataTransformers$DataTransformer")
    byID := make(map[string]model.ID)
    for _, ref := range refs {
        byID[ref.ID] = model.ID(ref.ContainerID)
    }
    // Step 2: 解码 gen 类型
    gs, _ := mprread.ListDataTransformers(r)
    // Step 3: gen → model（含 Steps）
    out := make([]*model.DataTransformer, 0, len(gs))
    for _, g := range gs {
        dt := &model.DataTransformer{
            BaseElement: model.BaseElement{ID: model.ID(g.ID())},
            ContainerID: byID[string(g.ID())],
            Name:        g.Name(),
            SourceType:  g.SourceType(),
        }
        for _, s := range g.StepsItems() {
            step, _ := s.(*genDT.Step)
            dt.Steps = append(dt.Steps, &model.DataTransformerStep{
                Technology: step.Technology(),
            })
        }
        out = append(out, dt)
    }
    return out, nil
}
