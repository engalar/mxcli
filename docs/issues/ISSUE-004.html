解决方案

SEM-L02（CheckStructural） 已在父 session 中实现，递归遍历 AST，对所有 $Var/id 模式报告结构性错误：

SEM-L02: 'id' is a reserved Mendix system attribute and cannot be read in expressions (in '$Instance/id').
  Fix: Use the object's business key attribute instead of the system 'id'.

此外，inferrer.go 已同步修复（commit 8a3c9ddd）：

// 单跳路径中 "id" 始终为 Long（系统主键）
if n.Path[0] == "id" {
    return exprcheck.KindLong
}

此修复使 $Entity/id 返回 KindLong 而非 KindUnknown，为结构检查提供准确的类型信息，避免类型推断链路中断。
