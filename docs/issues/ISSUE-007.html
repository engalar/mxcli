关键发现：CE0117 ≠ 类型不匹配

Mendix CE0117 是通用错误代码 "Error(s) in expression"，包含多种子类型：

  • ✗ 类型不匹配 → SEM-03（我们已实现，但仅覆盖 1 个）
  • ✗ 在 List 变量上访问属性 → 需新规则
  • ✗ 访问保留属性 id → 需新规则
  • ✗ 引用不存在的变量 → 需新规则（SEM-08）
  • ✗ 函数参数类型错误 → E006 增强
原规格"SEM-03 覆盖 41 个 CE0117"的假设来自于对 CE0117 的误解。 CE0117 是 Mendix 编译器的通用错误码，不等于"类型不匹配"。
SEM-03 的实际定位（重新确认）
SEM-03 实现是正确的，它能检测真正的表达式类型不匹配。macnica 中确实存在 1 个真实的类型不匹配 （Object → String），已被正确检测。

SEM-03 的价值在于防止类型错误，而不是覆盖所有 CE0117。 CE0117 中的大多数问题需要其他规则来检测。
