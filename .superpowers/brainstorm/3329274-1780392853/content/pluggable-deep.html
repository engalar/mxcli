目标

  WidgetID: "com.mendix.widget.custom.datagrid2.DataGrid2"
  RawType: bson.D ← 完整保留 schema（$ID + TypePointer 关系）

关键约束：TypePointer 是 schema 和 instance 的强引用

TypePointer 引用链——破坏这个链就会导致 Studio Pro CE0463

Type.ObjectType.PropertyTypes[i].$ID = "ddd-444" ←→ Object.Properties[i].TypePointer = "ddd-444"
Type.ObjectType.PropertyTypes[i].ValueType.$ID = "eee-555" ←→ Object.Properties[i].Value.TypePointer = "eee-555"

⚠ 修改 Properties 时必须维持这些 $ID 引用完整。这是 AugmentTemplate() 存在的原因。

AugmentTemplate 的工作：MPK 升级时同步 schema 和 instance

对 IR 设计的影响：RawType 是必需字段
⚠ RawObject 单独不够。 Object.Properties 的每个 TypePointer 必须匹配 Type.PropertyTypes 的 $ID。如果只保留 RawObject 而丢弃 RawType，写回时 TypePointer 引用会断裂，Studio Pro 报 CE0463。

修正后的 PluggableWidget IR 设计

type PluggableWidget struct {
    Name     string
    WidgetID string         // "com.mendix.widget.custom.datagrid2.DataGrid2"

    // 完整保留 schema + instance（TypePointer 引用链完整）
    RawType   bson.D          // CustomWidgets$CustomWidgetType（PropertyTypes + $IDs）
    RawObject bson.D          // CustomWidgets$WidgetObject（Properties + TypePointers）

    // 可读写的 child widget 槽（从 Object.Properties 中提取的 Widgets 类型属性）
    Slots map[string][]Widget  // key = PropertyKey, value = 子 widget 列表

    // 可读的已知属性（从 Object.Properties 中提取的简单值）
    DataSource *DataSourceDef  // 对应 key="datasource" 的属性
    Props      map[string]string // 其他可读标量属性（pageSize, selection 等）
}

// 读取：完整保留 RawType + RawObject
func (c PluggableCodec) HydrateFromBSON(doc bson.D) (Widget, error) {
    pw := &PluggableWidget{
        WidgetID:  extractCustomWidgetIDStr(doc),
        RawType:   dGetDoc(doc, "Type"),      // ← schema 完整保留
        RawObject: dGetDoc(doc, "Object"),    // ← instance 完整保留
        Slots:     extractNamedSlots(doc),     // ← Widgets 类型属性提取
        DataSource: extractPluggableDataSource(doc),
    }
    return pw, nil
}

// 写回：TypePointer 链完整，仅更新 Slots 中的 child widgets
func (c PluggableCodec) ToBSON(w Widget) bson.D {
    pw := w.(*PluggableWidget)
    // 将更新后的 Slots 写回 RawObject 中对应的 Widgets 属性
    updatedObj := updateSlotsInObject(pw.RawObject, pw.Slots)
    return bson.D{
        {"$Type", "CustomWidgets$CustomWidget"},
        {"Name", pw.Name},
        {"Type", pw.RawType},      // ← schema 原封写回
        {"Object", updatedObj},    // ← TypePointer 完整，Slots 已更新
    }
}
Augment 集成：MPK 版本升级时自动同步

当 widget 版本升级时

// 写回前检查是否需要 augment
func (c PluggableCodec) ToBSON(w Widget) bson.D {
    pw := w.(*PluggableWidget)
    def := widgetRegistry.GetDef(pw.WidgetID)
    if def != nil {
        // 用最新 MPK 定义 augment：
        // 加新属性对，移除废弃属性对
        tmpl := loadTemplate(pw.WidgetID)
        widgets.AugmentTemplate(tmpl, def)
        pw.RawType = tmpl.Type
        pw.RawObject = tmpl.Object
    }
    ...
}

当没有 MPK 定义时

// 未知 widget（WidgetID 不在 registry 中）
func (c PluggableCodec) ToBSON(w Widget) bson.D {
    pw := w.(*PluggableWidget)
    // 无 def → pure write-through
    // RawType + RawObject 原封写回
    // 不会丢失任何 Properties

        pw.Name, pw.RawType, pw.RawObject)

△ 保守：不 augment，但不丢数据

✓ 完整推演结论

1. MPK def.json → BSON Type (schema)：PropertyTypes[] 定义每个属性的 $ID、类型、嵌套结构
2. BSON Object (instance)：每个 Property 的 TypePointer 引用 Type.$ID，引用链不可破坏
3. IR 必须保留 RawType + RawObject（不能只保留 RawObject）
4. Slots 更新：通过 PropertyKey 定位对应 Property，只替换其 Value.Widgets
5. Augment 集成：MPK 升级时调用现有 AugmentTemplate()，TypePointer 链自动同步
6. 未知 widget：pure write-through，zero data loss
